5. HTML DOM

The HTML DOM (Document Object Model) represents this webpage as a tree of elements, where every tag is a "node" that can have parent and child relationships with other tags. Below is a screenshot of this page's DOM tree taken from my browser's DevTools (right-click → Inspect → Elements panel).
